# Tools &amp; Resources

Below are tools and resources you can use to mod Rhythm Heaven Groove.

## General
- [RHG Modding Chart](https://docs.google.com/spreadsheets/d/1fNTPlvIgDfWSvFVCRNZd32DnlALNa1PKKJYqm2MFd_8/edit?usp=sharing): A spreadsheet detailing info about each minigame
- [RHModding Discord Server](https://discord.gg/MzQvG2BZDX): The primary place for discussion & development of Rhythm Heaven mods for any game in the series. If you have any questions, we'd love to help!

## Text
- [MSBT Editor Reloaded](https://github.com/IcySon55/3DLandMSBTeditor): A GUI tool for editing MSBT text files. (Windows only)

## Audio
- [CWVTool](https://github.com/conhlee/cwvtool): A command-line tool for decoding and encoding cwv audio files

## Visuals
- [TEXTool](https://github.com/conhlee/textool): A command-line tool for decoding and encoding tex texture files

## Custom Levels
- [Metronome](https://github.com/ThatZeoGal/Metronome): A command-line tool for creating and reading wavmark (wvb) tempo files
