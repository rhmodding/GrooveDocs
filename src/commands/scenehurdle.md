## Commands
### `FUN_71001b1fc0(slide)` - Spawn Obstacle
_Function address: 0x71001b1fc0_
```
Usage - to be added when tools are developed
```
Spawns an obstacle up ahead. The input is always 8 beats after the command. A hop obstacle's first cue sound is 6 beats after the command, and a slide obstacle's first cue sound is 6.5 beats after the command.
|Argument|Type|Description|
|--------|----|-----------|
|`slide`|`bool`|Toggles if the obstacle should be one to slide under.|
