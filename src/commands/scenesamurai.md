# Spirit Slasher (SceneSamurai)

**Used in**: _Spirit Slasher_, _Remix 6_, _Remix 8_, _Spirit Slasher 2_, _Remix 12_, _Remix 17_, _Remix 20_

## Commands
### `FUN_710022ad50(slashNumber, totalSlashesInChain)` - Single Slice
_Function address: 0x710022ad50_
```
Usage - to be added when tools are developed
```
Slash two spirits with a single slice, either by itself or as part of a chain. The first cue sound is 2 beats after the command, and the input is 5 beats after the command.
|Argument|Type|Description|
|--------|----|-----------|
|`slashNumber`|`int`|The number of the slash in the chain, counting up. If this slash is by itself, this should just be 1.|
|`totalSlashesInChain`|`int`|The total number of the slashes in the chain. If this slash is by itself, this should just be 1.|
