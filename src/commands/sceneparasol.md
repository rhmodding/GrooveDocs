## Commands
### `FUN_7100204970(interval, type, unknown1, unknown2)` - Open/Close Umbrella
_Function address: 0x7100204970_
```
Usage - to be added when tools are developed
```
Open or close the umbrellas from left-to-right, starting 3 beats after the command. Cho-pa!
|Argument|Type|Description|
|--------|----|-----------|
|`interval`|`int`|The time in ticks between each performer's turn.|
|`type`|`int`|The action to perform.<br>0 = Close Umbrella<br>1 = Open Umbrella|
